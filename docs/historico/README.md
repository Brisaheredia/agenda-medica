# Documentación histórica

Los textos de esta carpeta describen etapas anteriores y **no son guías vigentes**. La entrada actual es el [README general](../../README.md) y el [índice técnico](../README.md).

- [Primera etapa del frontend](frontend-etapa1.md).
- [Etapa final anterior del frontend](frontend-etapa-final.md).

Se conservan para explicar la evolución del proyecto. Algunas afirmaciones sobre demo, pantallas pendientes o duración ya no coinciden con el código revisado. Las versiones anteriores del README, API, arquitectura y modelo de datos están conservadas por Git; no se duplican como otra documentación activa. Por ejemplo, `git show 96fc37a:README.md` permite consultar el README anterior a esta reorganización.

La especificación inicial es una [referencia de requisitos](../referencias/README.md), no un manual de la interfaz actual.
